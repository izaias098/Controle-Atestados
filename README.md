# Controle de Atestados

Sistema de controle de atestados desenvolvido em **Python** como projeto de estudo e prática de programação.

## 📌 Sobre o projeto

O sistema permite cadastrar e gerenciar atestados de forma simples através de um menu interativo no terminal.

O projeto foi desenvolvido para colocar em prática conceitos fundamentais da linguagem Python e criar uma aplicação funcional.

## ⚙️ Funcionalidades

* Cadastrar atestado
* Ver atestados pendentes
* Marcar atestado como concluído
* Ver todos os atestados cadastrados
* Salvar os dados automaticamente em um arquivo JSON
* Carregar os dados salvos ao iniciar o programa
* Validação de entradas do usuário
* Menu interativo
* Opção para sair do programa

## 🛠️ Tecnologias utilizadas

* Python
* JSON

## 📚 Conceitos praticados

Durante o desenvolvimento, foram utilizados conceitos como:

* Variáveis
* Listas
* Dicionários
* Funções
* `if`, `elif` e `else`
* `while`
* `for`
* `try` e `except`
* `append()`
* Leitura e escrita de arquivos
* Persistência de dados com JSON

## ▶️ Como executar

1. Tenha o Python instalado.
2. Baixe ou clone este repositório.
3. Abra o terminal na pasta do projeto.
4. Execute:

```bash
python controle_atestados.py
```

O objetivo principal deste projeto foi transformar os conhecimentos adquiridos durante os estudos de Python em uma aplicação prática e funcional.
